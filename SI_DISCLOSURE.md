# Development and SI disclosure

ChatGPT/Codex assisted coding, debugging, English text drafting, game mechanics and the creation of SVG module illustrations and CSS scenery. All SVG artwork and game scenery are SI-generated and visibly labeled in the interface, scene captions and SVGs. The HTML includes generator metadata and the JavaScript includes a development disclosure. No external image or audio generation service, live AI API or NASA data feed is used.

NASA educational resources are paraphrased in the Science Notebook and contextual mission debriefs. Game quantities remain original teaching assumptions. No NASA logos, flags or mission identifiers are generated in the game or demonstration deck. The team avatar on the Space Apps page was supplied separately by the owner and has not been reviewed for provenance.

Tools: ChatGPT/Codex, HTML/CSS/JavaScript, inline SVG, Node.js for packaging and checks, GitHub Pages for hosting.
